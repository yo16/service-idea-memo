## 使い方

このリポジトリで Claude Code のセッションを開き、話しかけて使う。

- 登録: 「〜というサービスを作りたい」と伝えると、`ideas/` に 1 件 1 ファイルで保存し、commit と push まで行う。
- 一覧: 「アイデアのリストをください」と伝えると、`ideas/` を読んで一覧にする。
- 更新: 「〜は検討中にして」「〜に〜を追記して」と伝えると、該当するファイルを直す。

Claude Code への指示は `CLAUDE.md` にある。
